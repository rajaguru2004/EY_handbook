## 1. The EY Recruitment Funnel

EY hires freshers in India through several parallel channels. The aptitude test appears in almost all of them.

```
┌─────────────────────────────────────────────────────────────┐
│  ROUND 1  │  Resume Shortlisting / Eligibility Screening     │
│           │  (CGPA cutoff, typically 60%+ or 6.0+ CGPA,      │
│           │   no active backlogs, gap-year limits)           │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  ROUND 2  │  ONLINE APTITUDE TEST  ◄── THIS HANDBOOK         │
│           │  Numerical + Verbal + Logical + SJT (+ Coding)   │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  ROUND 3  │  Technical / Functional Interview                │
│           │  (Domain, projects, tools; SQL/Excel for GDS)    │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  ROUND 4  │  Group Discussion / Case Study (campus drives)   │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  ROUND 5  │  HR Interview + Offer                            │
└─────────────────────────────────────────────────────────────┘
```

**Hiring channels where this test appears:**

| Channel | Description | Aptitude test? |
|---|---|---|
| **On-campus placement** | Tier 1/2/3 college drives | Yes — full pattern |
| **EY GDS off-campus** | Role-specific requisitions, year-round | Usually — shorter pattern |
| **EY GDS walk-in drives** | Bangalore / Pune / Hyderabad / Kochi / Chennai / Trivandrum / Noida | Sometimes — abbreviated |
| **Unstop / Superset / hiring-platform drives** | Hosted challenges | Yes — platform-dependent |

> **Key insight:** Unlike TCS NQT or Cognizant's GenC, **EY does not run a single standardised national test**. The pattern is assembled per requisition. This is why you must prepare *breadth-first* across all four sections rather than betting on one exact format.

## 2. The Aptitude Test — Reported Patterns

Three formats dominate reports from 2024–2026. Prepare for all three; they share the same underlying syllabus.

### Pattern A — The "Short & Fast" Format (most frequently reported)

| # | Section | Questions | Time | Sec/Question |
|---|---|---|---|---|
| 1 | Situational Strength / Judgement | 20 | 15 min | 45 s |
| 2 | Numerical Ability | 12 | 10 min | 50 s |
| 3 | Verbal Ability | 12 | 9 min | 45 s |
| 4 | Logical Reasoning | 12 | 8 min | 40 s |
| | **TOTAL** | **~56** | **~42 min** | **~45 s** |

- **Sectional timing:** Yes — you cannot carry unused time forward
- **Negative marking:** No
- **Character:** Extremely time-pressured. Speed > depth.

### Pattern B — The "Full Technical" Format (engineering / GDS Tech roles)

| # | Section | Questions | Time | Sec/Question |
|---|---|---|---|---|
| 1 | English / Verbal Ability | 12 | 18 min | 90 s |
| 2 | Quantitative Aptitude | 12 | 12 min | 60 s |
| 3 | Reasoning Ability | 12 | 12 min | 60 s |
| 4 | Computer Programming (MCQ) | 20 | 20 min | 60 s |
| 5 | Situational Strength | 20 | 20 min | 60 s |
| | **TOTAL** | **76** | **82 min** | **~65 s** |

- **Sectional timing:** Yes
- **Negative marking:** No
- **Character:** Moderate. The programming MCQ section covers C/C++/Java/Python output prediction, OOP concepts, DBMS/SQL, OS, and data structures basics.

### Pattern C — The "Equal Blocks" Format (consulting / global assessment vendor)

| # | Section | Time | Content |
|---|---|---|---|
| 1 | Numerical Reasoning | 20 min | Chart/table-driven data interpretation |
| 2 | Verbal Reasoning | 20 min | Passage → True / False / Cannot Say |
| 3 | Logical / Inductive Reasoning | 20 min | Abstract figure sequences, pattern matrices |
| 4 | Situational Judgement | 20 min | Workplace scenario ranking |
| | **TOTAL** | **~80 min** | |

- **Character:** This resembles the classic psychometric-vendor style (SHL/Cubiks-like). Numerical reasoning here is *almost entirely* data interpretation — very little pure arithmetic.
- Some 2025–26 drives have added a **"Job Simulation" / gamified assessment** module in place of, or in addition to, the SJT.

### What is common across all three

| Feature | Status |
|---|---|
| Negative marking | ❌ **None reported** → **attempt every question** |
| Sectional time limits | ✅ Yes, in nearly all reports |
| On-screen calculator | ⚠️ Sometimes in DI sections; **assume not available** |
| Back-navigation within a section | ⚠️ Often disabled — decide and move on |
| Webcam / proctoring | ✅ Yes for remote tests |
| Rough sheet | ✅ Usually 1–2 blank sheets permitted |
| Adaptive difficulty | ⚠️ Reported in some vendor-hosted numerical sections |

> **The single most important consequence of "no negative marking":**
> **Never leave a blank.** With 4 options, a blind guess is worth +0.25 marks in expectation. With 30 seconds left and 5 unanswered questions, mark all 5 — statistically you gain over a full mark.

## 3. Section-by-Section Breakdown

### 3.1 Numerical Ability / Quantitative Aptitude

The highest-scoring section for a prepared candidate, and the one this handbook covers most deeply.

**Two flavours appear:**

1. **Pure arithmetic MCQs** — percentages, profit-loss, time-work, TSD, interest, ratios, averages, number system, P&C, probability, mensuration.
2. **Data Interpretation sets** — a table / bar chart / pie chart / line graph followed by 3–5 questions. **This is the dominant flavour in Pattern C** and is heavily represented in Patterns A & B too.

**What EY tests that many candidates under-prepare:**

- **Percentage change chains** inside DI ("revenue rose 12% then fell 8%")
- **Ratio → actual value conversion** from pie charts
- **Approximation** — the options are usually far enough apart that a 2-significant-figure estimate wins
- **Multi-chart cross-referencing** — one question needing data from two different exhibits

### 3.2 Logical / Reasoning Ability

**Verbal-logical types (Patterns A & B):**
Series, coding-decoding, blood relations, direction sense, seating arrangements, syllogisms, statement–conclusion/assumption, data sufficiency, analogies, odd-one-out, Venn diagrams, cubes and dice.

**Abstract/inductive types (Pattern C):**
Figure sequences, matrix completion, next-in-series shapes. These test rotation, reflection, count progression, shading rules, and element addition/subtraction.

### 3.3 Verbal Ability / English

| Sub-topic | Typical share |
|---|---|
| Reading Comprehension | 30–40% |
| Sentence correction / error spotting | 15% |
| Fill in the blanks (grammar + vocab) | 15% |
| Synonyms & Antonyms | 15% |
| Para jumbles | 10% |
| One-word substitution, idioms | 5–10% |

In **Pattern C**, verbal reasoning is the strict **True / False / Cannot Say** format — a distinct skill covered separately in this handbook.

### 3.4 Situational Judgement / Strength Test

Not "aptitude" in the arithmetic sense, but it carries **20 of ~56 marks in Pattern A** — over a third of the paper. Ignoring it is the most common preparation mistake.

You are shown a workplace scenario and asked to rate responses (Most Effective → Least Effective), or to pick the action you would most/least likely take.

EY scores these against its own competency framework. See **Topic 22** for the full decoding.

## 4. Difficulty Calibration

| Section | Difficulty | Comparison anchor |
|---|---|---|
| Numerical Ability | **Moderate** | Harder than TCS NQT arithmetic; easier than CAT quant |
| Data Interpretation | **Moderate–Hard** | Comparable to bank PO prelims DI |
| Logical Reasoning | **Moderate** | Comparable to Capgemini / Deloitte |
| Verbal Ability | **Easy–Moderate** | Comparable to Infosys / Wipro |
| Programming MCQ | **Moderate** | Standard CS fundamentals |
| Situational Judgement | **Subjective** | No "difficulty" — pattern-recognition of EY values |

**Overall verdict: Moderate.** The difficulty is **not** in the mathematics — it is in the **clock**. At ~45 seconds per question in Pattern A, a question you could solve in 3 minutes is a question you will get wrong. This handbook therefore weights **shortcuts and elimination** as heavily as it weights method.

## 8. Test-Day Strategy & Time Management

### 8.1 The Three-Pass Method

Because sections are individually timed and back-navigation is often disabled, adapt:

**If back-navigation is ENABLED:**

| Pass | Time budget | What you do |
|---|---|---|
| **Pass 1** | 50% of section time | Answer only what you can solve in <40 s. Flag the rest. **Do not get stuck.** |
| **Pass 2** | 35% | Return to flagged questions. Solve the medium ones. |
| **Pass 3** | 15% | Guess-fill every remaining blank. Verify nothing is unanswered. |

**If back-navigation is DISABLED (common):**

Use a hard **75-second rule**: if you have not identified a path to the answer in 20 seconds, immediately switch to elimination. If elimination leaves 2 options, pick one and move on. **Never exceed 75 seconds on any single question.**

### 8.2 Per-Section Tactics

**Numerical Ability**
- Scan the options *before* solving. Widely-spaced options ⇒ approximate.
- For DI sets, spend the first 20 seconds *reading the axis labels and units* ("in ₹ crore", "in thousands", "% of total"). Most DI errors are unit errors, not arithmetic errors.
- Do the DI question that needs one data point before the one that needs a ratio of sums.

**Verbal Ability**
- Read the RC **questions first**, then the passage. You are hunting, not studying.
- In Pattern C's True/False/Cannot Say: **"Cannot Say" is correct more often than candidates expect.** If the passage does not explicitly support it, it is not True — even if it is true in the real world.

**Logical Reasoning**
- Draw. Always draw. Blood relations, directions, and seating are error-prone in your head and near-trivial on paper.
- For syllogisms, draw the Venn diagram for the *least restrictive* case first.

**Situational Judgement**
- Answer as **"an EY consultant in their first year"** would, not as your ideal self and not as a hero.
- The consistently correct instinct: **gather information → consult the right stakeholder → act within your authority → escalate transparently if blocked.**
- Wrong instincts: acting unilaterally on incomplete information; going over your manager's head first; doing nothing; covering up a mistake; blaming a colleague.

### 8.3 The Guessing Protocol

With no negative marking:

```
Time remaining in section < 60 seconds?
    → STOP solving.
    → Mark an option for EVERY unanswered question.
    → If truly random, keep to ONE letter (e.g. all "C") — it's
      as good as any, and it's faster than choosing.
```

Expected gain from blind-filling 8 questions in a 4-option MCQ = **+2 marks**. That is often the entire gap between shortlisted and rejected.

### 8.4 Common Failure Modes

| Mistake | Cost | Fix |
|---|---|---|
| Sinking 4 minutes into one hard question | −3 easy questions | Enforce the 75-second rule |
| Leaving blanks | −2 to −3 marks | Guess-fill protocol |
| Misreading DI units (crore vs lakh, % vs absolute) | Whole DI set wrong | 20-second exhibit scan first |
| Skipping the SJT prep | Up to 35% of the paper | Study Topic 22 |
| Calculating exactly when options are far apart | Time | Approximate to 2 significant figures |
| Not memorising tables/squares/fractions | ~20% slower throughout | See Master Revision Sheet |

## 9. How to Use This Handbook

Each topic file follows the same fixed structure so you always know where to look:

```
  1. Why This Topic Matters for EY     — weightage & question styles
  2. Core Concepts                     — plain-language explanation
  3. Formula Bank                      — every formula, in a table
  4. Shortcuts & Tricks                — the speed layer
  5. Solved Examples                   — worked step-by-step, with reasoning
  6. Practice Questions                — 50+, split Easy / Medium / Hard
  7. Detailed Solutions                — every question, fully worked
  8. Quick Revision Sheet              — one-page recall card
  9. Common Mistakes                   — what costs marks
```

**Recommended workflow per topic:**

1. Read sections 1–4 (**20 minutes**)
2. Work through the solved examples *with a pen*, covering the solution (**20 minutes**)
3. Attempt the Easy set **untimed** (**25 minutes**)
4. Attempt the Medium set at **60 seconds/question** (**20 minutes**)
5. Attempt the Hard set **untimed**, then re-attempt timed (**25 minutes**)
6. Read the Quick Revision Sheet and Common Mistakes (**10 minutes**)
7. Re-read *only* the Quick Revision Sheet 48 hours later (**3 minutes**)

That last step — the 48-hour spaced repeat — is what moves formulas into recall.
